\chapter{研究现状}

\section{定向光学链路}

定向交互需要在“人所指向或观察的对象”与“实际交换数据的设备”之间建立直接对应。射频链路具有覆盖广、穿透性强和网络生态成熟等优势，却通常将多个空间方向上的设备纳入同一发现范围。光学无线通信则受发射光束、接收视场和视距关系约束，能够在物理层将通信范围限定在局部空间。因而，光学链路的方向性不仅是一种信道特性，也可以成为对象选择和身份绑定的交互资源。

早期定向光学系统主要使用主动发光器或静态光学标记。FindIT Flashlight 使用手持光束唤醒并定位特定标签，展示了用“照向”动作筛选附近物体的可行性\parencite{findit}。PixNet 使用 LCD 与摄像头建立具有空间分辨能力的光学链路\parencite{pixnet}；InfoLED 和 LightAnchors 则将现有 LED 指示灯复用为设备身份与增强现实空间锚点\parencite{infoled,lightanchors}。这类方法能够把数字信息附着到具体位置，但主动发光会增加对象端功耗，而静态标记不能根据对象状态动态返回信息。

无源光学链路为低功耗反向通信提供了另一条技术路径。典型系统包含主动读写器和无源或低功耗光标签：读写器负责发射照明或调制光，逆反射材料把入射光返回光源方向，液晶等空间光调制器再通过改变光学状态将数据调制到回波中。Retro-VLC 首次将逆反射材料与液晶调制器结合，构建了面向移动和物联网设备的双工可见光反向链路\parencite{retrovlc}。PassiveVLC 进一步通过器件与编码协同设计，提高无电池标签通信的可用性\parencite{passivevlc}。

在此基础上，后续研究主要围绕数据率、距离、抗环境光干扰以及多标签接入展开。TurboBoosting 利用多级调制和链路协同设计提升可见光反向散射的通信性能\parencite{turboboost}。参考报告对这条技术脉络的总结表明，现有系统已在物理层实现低功耗上行，但其常用设计仍是“单读写器---单标签”链路；当多个标签的反射信号同时到达接收器时，传统时分机制会使延迟随节点数量增长。因而，如何利用光束的空间可分性避免非目标响应，是无源光学网络从单链路走向密集场景的核心问题。

上述工作主要将无源光学链路视为低功耗通信系统，而 RetroAR 进一步将光束方向解释为用户的目标选择。该系统以商用智能手机的闪光灯和后置摄像头作为读写器，并使用多像素液晶逆反射标签 ViTag 承担数据传输与空间锚定。标签在时域与空间域中编码返回数据，手机在解码的同时进行标签跟踪和六自由度位姿估计。这一设计使“手机指向”、“设备识别”与“获取控制信息”在同一光学链路中完成，避免了再从 Wi-Fi 或蓝牙列表中查找目标\parencite{retroar}。

EchoSight 则把无源定向链路从手持设备迁移到智能眼镜。系统包含眼镜端读写器 SightReader 和对象端标签 EchoTag，通过双光学元件的近红外链路实现局部双向数据交换。用户看向目标并作出手势后，标签返回设备身份和交互菜单，后续指令仍被限定在当前光学链路中。其系统评估表明，该链路可以支持房间尺度的交互距离和视角，说明近红外逆反射链路可以被整合到轻量级佩戴式交互系统中\parencite{echosight}。

定向光学链路的研究因此呈现出从“实现通信”到“支持空间交互”的演进。但现有系统仍存在三方面局限。首先，光学接收会受环境光、反射噪声、观察距离和入射角影响，移动过程中需要同时保证检测、跟踪与解码稳定性。其次，手机或眼镜的光轴只能表示设备方向，不能完全代替用户的真实视线与操作意图。最后，全光会话对视距的依赖会限制遮挡条件下的持续交互。如何在保留光学方向性的同时，使空间选择、真实注视和持续会话相互配合，仍是定向光学交互需要解决的问题。

\section{注意力驱动的直观交互}

智能环境中的上下文感知交互，通过利用用户的位置、朝向、动作和周边物体状态，减少人对菜单层级与设备名称的记忆负担。在多对象环境中，这类系统通常需要回答两个问题：用户当前关注的是哪一个对象，以及用户希望对该对象执行什么动作。因此，注意力驱动交互并不是单一的输入模态，而是将指向、头向、注视等注意代理线索贯穿到对象发现、身份绑定和动作反馈的交互方法。

对象识别是这类研究的主要起点。二维码、ARTag 等人工标记可以同时编码身份与提供几何定位，具有识别简单、结果明确的优势；其局限是标记需要处于摄像头视野内，还可能破坏物体外观。基于自然特征的方法可以避免附加可见标记，但在弱纹理、外观相似、快速运动或局部遮挡时易出现不稳定，并且需要较多计算资源\parencite{wagnertracking}。Snap-to-it 允许用户通过拍摄目标图像完成偶发式设备选择，但需要云端识别与预先准备的视觉数据\parencite{snaptoit}。

为了降低显式标记与纯视觉匹配的局限，一些工作开始利用射频测位或异构传感信息缩小候选范围。Bluewave 把短上下文信息嵌入蓝牙设备名称，以降低连接前的信息获取成本\parencite{bluewave}。Scenariot 结合超宽带定位与同步定位建图，将智能对象映射到增强现实场景中\parencite{scenariot}。BLEselect 使用智能眼镜上的蓝牙到达角估计感知手势方向，将空间指向与无线身份关联\parencite{bleselect}。IRIS 则将指环的无线感知与手机图像、惯性数据结合，实现智能家居的指向控制\parencite{iris}。这些方法提高了空间分辨能力，但通常仍需要设备预注册、环境建图或局域网络连接。

另一类研究关注虚拟世界与物理对象之间的双向同步。BISHARE 支持智能手机与头戴式增强现实设备之间的双向绑定，使手机的物理位置和姿态可被头显感知，手机又可作为虚拟内容的控制器\parencite{bishare}。Sketched Reality 将用户绘制的虚拟草图转化为物理机器人动作\parencite{sketchedreality}；MechARspace 则在增强现实界面与可动玩具之间建立实时映射\parencite{mecharspace}。这些系统表明，直观交互不应止于识别一个对象，还需要使物理状态、虚拟表示和用户动作持续一致。

然而，现有双向虚实系统在“识别对象”与“控制对象”之间往往使用不同机制。InfoLED 与 LightAnchors 通过光学方式获取就地信息，但对设备的后续控制仍依赖蓝牙或 Wi-Fi\parencite{infoled,lightanchors}。当场景中存在多个同类对象时，系统必须另外维护光学识别结果与无线地址的映射。这种分离设计虽然可以充分利用成熟网络，却容易在目标切换、设备移动或数据库更新不及时时形成对象绑定断点。

RetroAR 与 EchoSight 的重要转变，在于将用户已经表达的空间关注直接保留到数据链路中。RetroAR 以手机指向作为强外显选择线索，用户必须主动举起设备并对准目标，因而“指向”本身同时表达了注意范围与一定程度的交互意愿\parencite{retroar}。EchoSight 转而使用头戴式设备的朝向近似用户的观察方向，使目标识别、菜单获取与控制命令都可以通过局部光学链路完成\parencite{echosight}。其用户研究将交互时间分解到识别、连接与命令执行阶段，结果表明，在短时物联网任务中，简化目标识别和连接准备对整体流畅性的影响大于单纯改善数据传输延迟。

现有研究已经证明，方向、位置与注视等线索可以降低多对象选择的显式操作开销，但仍未完全解决注意力的两重不确定性。第一，设备光轴、头部朝向与眼球视线并不总是一致，密集目标中仅依靠机身方向可能无法区分相邻对象。第二，准确的视线交点只说明用户正在观察，不能单独证明用户准备执行操作。因此，注意力驱动交互的下一步不只是换用更精确的眼动传感器，还需要研究视线与操作意图的区分。

\section{基于眼动、脑电信号的意图识别}

眼动是注意力交互中最直接的可观测信号之一。早期凝视交互已尝试使用视线指定界面元素，并通过凝视停留或辅助输入完成选择\parencite{jacobgaze}。与头向和手持设备指向相比，眼动的转移速度快、动作幅度小，能够在不占用双手的条件下指出视野中的感兴趣区域。随着眼动相机逐渐集成到头戴式设备中，凝视也成为增强现实和空间计算中用于目标指定、菜单导航和渲染优化的重要通道。

但凝视不是一种天然无误差的指针。眼动测量的准确度与精密度受标定质量、注视位置、用户个体差异和设备滑移影响，实际误差会直接限制相邻目标的最小可分距离\parencite{everydaygaze}。同时，人类视线在浏览环境时会自然扫过大量非操作对象。若系统把“看到”直接解释为“选中”，就会产生所谓的“米达斯接触”问题；若通过较长的凝视停留时间避免误触发，又会降低操作速度并带来视觉疲劳。

因此，大量凝视交互采用“视线定位+显式确认”的多模态思路。眼动先把较大的视觉场景缩小为少量候选目标，手势、按键、语音或肌电信号再确认动作。这种分工能够避免对眼动信号赋予过多含义，但其效率取决于确认模态是否与当前任务兼容。在双手被占用、必须保持安静或不方便作出明显动作的场景中，额外手势与语音可能重新引入交互负担。这促使研究者进一步探索能否从生理信号中获得与注意和行动准备相关的证据。

脑电图（Electroencephalography, EEG）具有无创、时间分辨率高和硬件可穿戴化等特点，是脑机接口中应用最广泛的信号之一。根据信号是否由外部刺激诱发，相关方法可概括为诱发电位与自发脑活动两类。前者包括 P300、稳态视觉诱发电位（Steady-State Visual Evoked Potential, SSVEP）等，通常通过用户对特定刺激的注意识别目标；后者包括感觉运动节律、运动想象以及与认知状态相关的频带特征。现有综述表明，EEG 脑机接口已形成从信号采集、预处理、特征提取到分类的完整技术链，但实用系统仍受低信噪比、非平稳性和个体差异限制\parencite{eegbcisurvey}。

P300 是与低概率、任务相关刺激相联系的事件相关电位。Farwell 和 Donchin 提出的 P300 字符输入系统使用稀有刺激范式，通过检测用户所关注行列诱发的 P300 响应确定目标字符\parencite{farwellp300}。这类方法不需要用户产生明显肢体动作，但为了对抗单次事件相关电位较弱的信噪比，往往需要多次刺激和时间锁定平均。当它被用于短时现场交互时，系统需要在准确率、响应时间和用户注意负担之间进行权衡。

SSVEP 利用用户观察周期性视觉刺激时，视觉皮层产生与刺激频率及其谐波相关的稳态响应。系统可以为多个界面选项分配不同频率或编码，再根据 EEG 的频谱或相关性判断用户关注的选项。这类系统通常具有相对稳定的频域特征和较少用户训练要求，是视觉脑机接口的主要路径之一\parencite{visualauditorybci}。但多个持续闪烁的刺激会影响视觉舒适度，且 SSVEP 本质上识别的是对特定刺激的选择性注意，未必等价于对现实对象执行某个控制动作的自发意图。

相较诱发电位，基于运动想象、感觉运动节律或其他自发特征的方法不必在环境中布置持续闪烁的外部刺激，更接近“从内部行动准备中识别意图”的目标。但这类信号对用户训练、个体化标定和电极质量更为敏感，也易受眼电、肌电和日常身体运动的伪迹干扰。这意味着，在可穿戴交互中直接使用 EEG 代替手势或按键，往往得不偿失；更可行的方向是把它视为一种辅助证据，而不是唯一命令通道。

从多模态融合角度看，眼动与 EEG 具有互补性。眼动能够快速给出用户正在观察的空间区域，但无法独立判断操作意图；EEG 可能提供与选择性注意、行动准备或认知评估相关的时序证据，却缺少对现实空间目标的精确指向。若先用眼动缩小对象范围，再在短时窗内利用 EEG 评估意图置信度，理论上可以减少单一模态的二义性。但融合系统必须处理两种信号的时间对齐、不同用户的模型适配、头部运动伪迹以及误判成本不对称等问题。

现有凝视与脑机接口研究多数聚焦屏幕上的离散选项、输入效率或辅助控制，而少有工作将其与现实世界多对象的身份绑定和通信会话同时考虑。EchoSight 已指出，对于高密度目标，可以结合头部朝向获取粗粒度关注范围，再使用眼动完成精细对准\parencite{echosight}。但眼动驱动光束定向、视线到物理标签的实时标定，以及 EEG 能否在自然观察中辅助区分“看见”与“准备操作”，仍缺少系统性验证。

\medskip
\noindent\textbf{研究空白与本文定位。}
现有工作已分别发展了方向性光学通信、上下文感知对象交互以及眼动/EEG 人机输入，但三个层面尚未形成一条连贯、可验证的行动链。方向性通信不必然等于真实注视，准确注视也不必然表示主动意图；当光学选择转入持续无线会话后，物理对象与数字身份的一致性也需要继续维持。

本文因此不把光学通信、眼动与 EEG 视为彼此并列的传感器，而是分别用于对象选择、视线对齐和意图判别。RetroAR、EchoSight 与 Omnisight 对应“所指即所控”、“所看即所控”与“所思即所控”三个逐级深入的层次。前两项工作验证方向性光学链路在手持与佩戴式交互中的可行性，第三项工作则进一步面向真实视线、操作意图与持续会话之间的断点展开研究。
