\chapter{本文工作及当前进展}
\section{技术挑战与研究思路}
在人机共生环境中，用户面对的不是一台预先连接的设备，而是分布在物理空间中的多个潜在交互对象。一次自然的定向交互，需要把用户“面向哪里”的空间线索依次转化为唯一的物理目标、可验证的数字身份、明确的操作意图和可持续的信息通道。现有视觉识别、无线发现和凝视输入通常分别解决其中一个环节，环节之间的割裂却会造成目标错选、身份错配、无意触发或会话中断。结合前两章对注意目标解析、物理--数字身份对齐和交互闭环保持的分析，本文需要解决三个逐层递进的系统性难题。

\textbf{受限移动终端上空间指向、对象身份与空间信息的一体化难题。} 用户用手机指向对象时，设备姿态提供了明确但短暂的空间选择线索；摄像头可以看到目标，却难以仅凭外观区分同类实体，无线发现可以获得设备地址，却不能证明该地址对应当前所指对象。如果目标选择、身份读取和空间注册分别依赖拍摄、扫码、设备列表与连接配置，用户就必须在物理对象和数字界面之间反复映射。与此同时，商用手机的闪光灯、滚动快门摄像头和有限算力又受到运动模糊、视角变化、环境光干扰和弱反射信号的共同约束。因此，第一个难题是在不增加专用读写器和预先无线配对的条件下，利用同一方向性光学过程完成目标筛选、身份获取、数据解码与位姿估计，使“指向的实体”与“读取的数字对象”在移动过程中保持一致。这一难题对应 RetroAR，构成注意力驱动定向交互的对象绑定基础。

\textbf{穿戴式观察条件下目标选择、双向通信与低负担操作的协同难题。} 将交互入口由手机迁移到智能眼镜，可以避免反复掏出和举起设备，使交互方向更贴近日常观察方向，但也削弱了“主动持机指向”所包含的明确操作信号。眼镜端还面临发射功率、接收视场、器件尺寸和佩戴姿态等限制；对象端既要准确接收眼镜发出的控制信息，又要把身份和状态沿原方向可靠返回，并避免环境光、邻近标签和非目标用户造成误响应。由此，第二个难题是在无需预注册和额外无线连接的条件下，将佩戴式方向选择、显式操作确认、目标端按需响应以及身份与状态回传组织为同一条低时延双向链路，使用户能够从“举机指向后读取”推进到“面向目标即可就地交互”。这一难题对应 EchoSight，并在 RetroAR 的单向信息获取和空间注册基础上，将系统能力扩展为面向同一对象的双向控制与反馈。

\textbf{自然注意条件下精确目标对齐、操作意图判别与持续会话的闭环难题。} 即使眼镜光轴能够近似表示观察方向，它仍不等于眼球的真实注视方向；即使视线已经落在某个对象上，也不能说明用户希望立即操作。标定误差、设备滑移、头眼协同和相邻目标会影响视线到对象的映射，自然扫视、信息查看与主动控制又可能表现出相似的注视行为，直接触发容易产生“米达斯接触”式误操作。进一步地，定向光适合核验当前目标，却会因转头、移动和遮挡而中断，不适合独自承担后续持续会话；蓝牙适合维持连接，却不能天然证明其设备身份就是用户刚刚注视的物理实体。因此，第三个难题是联合解决“真正看向谁、是否想操作、如何始终与同一对象交互”：既要以实测眼动驱动光束对齐和光学身份验证，又要检验脑电能否在眼动之外提供稳定且值得其佩戴成本的意图证据，还要建立光学目标标识与无线设备身份之间的可验证绑定，并处理授权、切换、超时、重绑定和会话恢复。这一难题对应 Omnisight，把前两项工作的对象绑定与就地交互进一步推进为低误触发、可持续的注意力交互闭环。

\textbf{研究思路。} 针对上述三个难题，本文按照“外化指向—贴近观察—解析意图”的注意力线索演进，以及“对象绑定—双向交互—持续闭环”的系统能力演进展开研究。首先，RetroAR 利用手机闪光灯、逆反射标签和后置摄像头构成同向可见光链路，在商用移动终端上验证空间指向能否统一目标选择、身份读取和空间定位；其次，EchoSight 将该方向性绑定机制迁移到智能眼镜，以眼镜端 SightReader 和对象端 EchoTag 构建双向近红外链路，研究低负担的就地识别、控制与反馈；最后，Omnisight 在前述光学对象绑定基础上引入实测眼动、主动可调光束和眼脑多模态判别，并以“光学选择与核验、蓝牙维持会话”的分层机制贯通目标、意图与后续操作。三项工作不是三个孤立系统，而是依次放宽主动手持、设备朝向和全光会话等假设，逐步检验从“所指即所控”到“所见即所控”，再到“所思即所控”的可行性及能力边界。

\section{本文主要工作及进展}\label{sec:current-progress}
本文以实现人机共生环境中的注意力驱动定向交互为研究目标，围绕目标选择、身份绑定、意图确认和会话保持等关键环节开展系统研究。三项工作分别以手机指向、眼镜观察方向和实测眼动为交互入口，按照“所指即所控—所见即所控—所思即所控”的路径逐步降低显式操作负担，并扩展系统对用户注意与交互意图的理解能力。具体研究内容与当前进展如下。

\medskip
\noindent\textbf{RetroAR：基于手机指向的可见光非接触定向交互系统。}
移动增强现实通常需要分别完成目标拍摄、标识扫描和无线连接，难以保证用户所指的物理对象与系统连接的数字设备一致。RetroAR 利用可见光的方向性保留手机指向所包含的空间信息，使目标选择、身份读取和空间注册在同一过程中完成。具体包括以下三个方面：
\begin{itemize}
  \item 定向通信与对象绑定：利用手机闪光灯照射逆反射标签 ViTag，由标签调制反射光并通过手机后置摄像头接收，以光束范围和成像位置共同约束候选对象，无须从无线设备列表中再次查找目标。
  \item 动态标签检测与移动解码：设计消息级动态兴趣区、快速凸包检测和自适应时空混合编解码，在手机运动、视角变化和复杂光学背景下稳定检测 ViTag 并恢复标签数据。
  \item 通信感知一体化空间注册：复用 ViTag 的光学几何特征，在完成身份与数据读取的同时估计目标六自由度位姿，使同一标签同时承担通信节点和增强现实空间锚点的功能。
\end{itemize}
该工作已完成系统设计、原型实现和实验评估。系统最远可在约 $4\,\mathrm{m}$ 距离和约 $100^\circ$ 视角下工作，位姿误差最低约为 $1\,\mathrm{cm}$ 和 $4.7^\circ$；用户研究中，交互开销较二维码与 Wi-Fi 基线降低约 $50\%$。相关成果发表于《电子学报》期刊。

\medskip
\noindent\textbf{EchoSight：面向智能眼镜的双向近红外直观交互系统。}
针对手持设备操作负担和单向信息获取的限制，EchoSight 将交互入口迁移到智能眼镜，并将观察方向近似作为目标线索。系统由眼镜端 SightReader 和对象端 EchoTag 构成双向近红外链路，使目标选择、命令发送和状态反馈围绕同一对象连续发生。具体包括以下三个方面：
\begin{itemize}
  \item 佩戴式双向交互架构：用户面向目标并进行手势确认后，SightReader 向 EchoTag 发送控制信息，EchoTag 再沿原方向返回身份与状态，从而减少举机、扫码、设备列表选择和预先无线配对等步骤。
  \item 互补光学前端与差分传输：设计双元件互补收发前端，以不同覆盖特性的光学器件扩展工作范围，并利用双波段差分信号抵消环境光变化，提高双向链路的可靠性。
  \item 对齐检测与按需响应机制：根据上下行光路状态判断眼镜与目标是否对准，并仅唤醒被选中的 EchoTag 进行应答，减少邻近标签串扰、非目标对象响应和对象端持续工作开销。
\end{itemize}
该工作已完成系统设计、原型实现和实验评估。系统最远可在约 $5\,\mathrm{m}$ 距离和约 $120^\circ$ 视角下工作；在 12 名参与者的多对象任务中，交互速度较二维码扫描和语音控制方案至少提升 5 倍，并降低了主观负担。相关成果发表于 ACM CHI 2025会议。

\medskip
\noindent\textbf{Omnisight：眼脑联合的注意力驱动意图交互系统。}
Omnisight 进一步面向目标对齐误差、注视与操作意图二义性以及全光链路易中断问题，将实测眼动、事件驱动脑电和混合通信链路组织为完整交互闭环。该研究的重点不是预设脑电能够直接读取意图，而是检验其能否在眼动之外提供稳定且值得佩戴成本的增量信息。具体包括以下三个方面：
\begin{itemize}
  \item 视线驱动的主动光路对齐：在眼镜端集成双目眼动追踪模块，标定眼动、头部姿态和光束坐标之间的变换，并驱动可调光学发射单元主动追随视线，研究多目标间距、运动和标定误差对目标绑定的影响。
  \item 眼脑联合的操作意图判别：同步采集眼动与水凝胶电极脑电，提取空间注视和事件驱动神经特征，通过多模态融合区分自然观察、状态查看与主动操作，并保留显式确认作为低成本基线。
  \item 光学选择与无线会话协同：以定向光完成目标发现、身份核验和初始授权，再将光学目标标识绑定到唯一蓝牙身份，由蓝牙维持后续命令与反馈，并实现切换、超时、重绑定和恢复机制。
\end{itemize}
目前已完成总体架构、研究问题和评估指标设计，眼镜原型、融合模型、混合链路协议及系统实验仍待完成。后续将通过光束对照、多模态消融和用户研究，综合报告目标错选、误触发、时延、会话恢复、功耗与佩戴负担；完成后计划将相关成果投稿至 ACM IMWUT 或 Nature Communications。
