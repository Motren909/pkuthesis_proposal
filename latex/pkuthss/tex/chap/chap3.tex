\chapter{本文工作及当前进展}
\section{技术挑战与研究思路}
在人机共生环境中，用户需要在多个共处对象之间快速切换，并把自然产生的空间关注转化为针对特定对象的操作。要实现这一目标，系统不能只解决单次识别或通信问题，而需要贯通“线索获取—对象绑定—意图确认—会话维持—动作反馈”的完整交互链。其关键技术挑战可归纳为以下三个方面。

\textbf{注意力线索的可靠获取与空间对齐。} 指向、头部朝向和眼球视线都能提供目标线索，但三者与真实关注对象之间存在不同程度的偏差。手机指向需要用户主动举机并保持对准；眼镜机身方向虽然更接近日常观察，却不能代表眼球实际注视点；实测眼动又受到标定误差、头部运动、目标距离和相邻目标间距的影响。因此，首先需要明确不同线索能够提供何种空间约束，并研究如何利用方向性光路将这些线索稳定地对齐到唯一物理对象，而不能简单地把设备朝向等同于人的注意力。

\textbf{目标注视与操作意图的可靠区分。} 即使系统能够准确判断用户正在看哪个对象，也不能据此认定用户准备执行操作。日常观察、状态检查、偶然扫视和主动选择可能产生相似的眼动表现，若直接以注视触发控制，容易产生“米达斯接触”式误操作。显式按钮或语音确认能够降低二义性，却会重新引入动作和认知开销；脑电等生理信号可能提供任务相关证据，但同时面临噪声、运动伪迹、个体差异和佩戴负担。因此，需要在相同任务中比较眼动、脑电、多模态融合与显式确认，判断生理信号是否真正带来足以覆盖其成本的增量收益。

\textbf{物理对象绑定与持续会话的一致性。} 定向光学链路适合利用空间方向发现目标和确认身份，但可能因转头、移动或遮挡而中断；蓝牙等无线链路适合持续传输，却不能天然保证设备列表中的数字身份就是用户刚刚关注的物理对象。若目标选择与后续通信彼此独立，便可能出现选中对象与实际控制设备不一致、切换后会话未及时更新等问题。因此，需要设计从光学目标标识到无线设备身份的可验证绑定，并处理授权、超时、切换、重绑定和会话恢复，使注意力线索不仅完成一次选择，还能可靠地贯穿后续控制与反馈。

\textbf{研究思路。} 本文按照注意力线索由间接到直接、系统能力由目标选择到行动判别的顺序展开研究。首先，RetroAR 将手机指向外化为可见光链路，验证方向性光学机制能否在同一动作中完成目标发现、身份读取与空间定位；其次，EchoSight 将交互入口迁移到智能眼镜，以双向近红外链路研究更接近日常观察的原位交互；最后，Omnisight 拟引入实测眼动驱动光束对齐，以眼动和脑电区分观察与操作意图，并通过光学选择与蓝牙会话的分层设计提升连接连续性。三项工作均按照“注意力线索—对象绑定—意图确认—会话与动作—实验评价—能力边界”的顺序分析，并以目标错选、误触发与漏检、时延、会话恢复、功耗和用户负担共同检验收益。

\section{本文主要工作及进展}
本文围绕注意力线索如何转化为可靠、可执行的定向交互，开展以下三项工作。

\medskip
\noindent\textbf{RetroAR：基于手机指向的可见光非接触定向交互系统。}
RetroAR 面向移动增强现实中的非接触定向交互\parencite{retroar}，利用手机闪光灯、逆反射标签 ViTag 与后置摄像头构成同向光学链路，使用户在指向物体的同时完成目标发现与局部信息读取。其核心贡献包括：
\begin{itemize}
  \item 提出面向商用手机的可见光定向交互机制，以光束方向和摄像头视场共同约束候选对象，将手机指向这一间接注意力线索转化为物理目标绑定；
  \item 设计消息级动态兴趣区、快速凸包检测、自适应时空混合解码与六自由度位姿估计，使系统能够应对手机运动、视角变化和复杂光学背景；
  \item 完成原型和用户研究评估：系统最远可在约 $4\,\mathrm{m}$ 距离和约 $100^\circ$ 视角下工作，位姿估计误差低至约 $1\,\mathrm{cm}$ 和 $4.7^\circ$，交互时间相较 Wi-Fi 基线减少两倍以上。
\end{itemize}
该工作验证了“所指即所控”的可行性，但仍要求用户举起并持续对准手机，使用的是设备方向而非真实视线，由此引出佩戴式观察方向能否替代手持指向的问题。

\medskip
\noindent\textbf{EchoSight：基于智能眼镜的双向近红外直观交互系统。}
EchoSight 将定向交互入口迁移到智能眼镜\parencite{echosight}，由眼镜端 SightReader 与对象端 EchoTag 建立双向近红外光学链路，使用户在观察目标时获取身份和状态并发送控制数据。其核心贡献包括：
\begin{itemize}
  \item 提出佩戴式原位双向交互架构，把对象选择、身份获取和命令传输放入同一现场通道，减少举机、扫码和预先无线连接步骤；
  \item 设计双元件互补光学前端、双波段差分信号、对齐检测与按需唤醒机制，抑制环境光干扰和非目标对象响应；
  \item 完成房间尺度原型和用户研究评估：系统最远可在约 $5\,\mathrm{m}$ 距离和约 $120^\circ$ 视角下工作；在 12 名参与者的实验中，相较二维码扫描和语音控制至少降低五倍交互延迟，并减小主观负担。
\end{itemize}
该工作验证了“所看即所控”在所设任务中的效率优势，但眼镜机身光轴只近似观察方向，不能测量真实注视点，也无法区分日常观看与操作意图；遮挡和转头还可能中断全光会话。

\medskip
\noindent\textbf{Omnisight：眼、脑联合的注意力驱动意图交互系统。}
Omnisight 拟进一步解决设备方向与真实视线的偏差、“看向”与“想操作”的二义性，以及全光链路难以持续维持会话的问题。计划开展的核心工作包括：
\begin{itemize}
  \item 在眼镜端测量眼动，标定眼动、头部姿态与光束坐标之间的变换，并驱动可调光学发射单元主动追随关注目标；
  \item 同步采集眼动与凝胶电极脑电，比较仅眼动、仅脑电、多模态融合以及眼动加显式确认，检验 EEG 对降低误触发是否具有稳定的增量价值；
  \item 以定向光完成目标发现和身份确认，再将授权物体绑定到蓝牙身份，由蓝牙维持反馈与后续会话，并设计超时、切换和重绑定机制；
  \item 通过固定/可调光束对照、多模态消融和完整任务用户研究，评价目标错选、误触发与漏检、决策及端到端时延、会话恢复、功耗和佩戴负担。
\end{itemize}
目前 Omnisight 的总体架构和实验问题已经明确，眼镜原型、脑电同步、融合模型及混合链路协议仍待实现和评估。若 EEG 无法提供足以覆盖采集与佩戴成本的稳定收益，将采用眼动加显式确认作为备选路线，并把这一适用边界作为研究结论。
